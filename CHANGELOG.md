# Changelog

## 0.2.0
- New UI built on course symbols: start triangle, control circles, finish double circle (magenta)
- Progress ring around the edge fills as controls are punched; turns yellow when paused
- Clock / PAUSED status at the top, page dots on the left
- HR coloured by zone, with zone number
- Done screen shows whether the race was saved or discarded

## 0.1.0
- Race mode: start / pause / save / discard, BACK punches a control (lap)
- Screens: main (next control, leg, total), body (HR, distances), last 5 splits
- Split popup + vibration after each punch
- Number of controls via on-watch picker or phone settings
- FIT: one lap per leg, `leg` lap field, `controls` session field
